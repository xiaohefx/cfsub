❓ 帮助

订阅地址怎么用？

在「节点信息」页复制对应格式的链接，粘贴到 Clash / Sing-box / v2rayN 等客户端的「从 URL 导入」即可。通用链接会根据客户端 UA 自动返回对应格式。

如何限制用户流量？

在「用户管理」里给每个用户设置总流量上限与每日上限（单位 GB）。超限后该用户会被自动拒绝连接，可在用户列表点击「重置」清零。

内置优选 IP 从哪里来？

内置资源来自 byJoey/cfnew（官方直连池、地区反代域名、优选域名表）、cmliu/edgetunnel（机房级反代、CF-CIDR 运营商分段）、BPB（NAT64 前缀）。全部可在「高级设置」中关闭或替换为自己的地址。

Kill Switch 是什么？

开启后 Worker 会拒绝所有代理连接（返回 503），仅保留面板访问，用于紧急止损。

自动更新怎么配置？

填写 GitHub 仓库（需包含 version 文件与 dist/_worker.js）、Cloudflare 账户 ID、API Token 与 Worker 名称，然后开启自动更新。Cron 会定时检查并调用 Cloudflare API 重新部署。

Pages 部署需要注意什么？

Pages 需要在项目设置的「Functions → KV 命名空间绑定」中添加变量名 CF_SUB_KV。Pages 不支持 Cron，自动更新需手动点击部署。
